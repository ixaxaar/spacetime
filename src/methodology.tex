\section{The framework}
\label{sec:framework}

\subsection{The object}

At any moment, the universe is a finite simplicial set with directed edges.
It begins as a single vertex $\Delta^0$, the big bang, and it grows from there.

The object is pre-geometric.
It is not spacetime, and it is not a representation of a spacetime lying elsewhere.
It carries no metric, no dimension, and no manifold structure.
Everything geometric has to be recovered from it.
Statements about space are made in the framework's own combinatorial terms.

\subsubsection{Growing the Simplicial Set}

\begin{definition}[]
\label{def:moves}

The simplicial set grows by two local, non-deleting \textbf{moves}, which are pushouts along the following two monomorphisms of finite simplicial sets:

\begin{enumerate}
  \item \textbf{Sprout:} $\Delta^0 \hookrightarrow \Delta^1$.
        A sprout can happen at any vertex $v$ of the current state.
        Performing it attaches a fresh directed edge from $v$ to a new vertex.
  \item \textbf{Fill:} $\Lambda^n_k \hookrightarrow \Delta^n$ for $0<k<n$.
        A fill can happen at any unfilled inner horn.
        Performing it attaches the missing face and interior.
        Each horn may be filled at most once.
\end{enumerate}

\end{definition}

\begin{remark}
The initial object is a single vertex $\Delta^0$ (the big-bang event). At any moment the current state is a finite simplicial set with directed edges, and the next move is chosen from the set of available moves, which is the disjoint union of all sprout sites and all unfilled inner horns.
\end{remark}

\begin{remark}
Every vertex is created by exactly one sprout, which supplies its first incoming edge.
Every other incoming edge is a composite supplied by a fill.
So sprout edges and composite edges never mix.
A sprout creates a fresh vertex and attaches a directed edge to it.
The composite joins two vertices that already exist.
\end{remark}

\begin{remark}
Sprouting is a Whitehead elementary expansion and inner-horn filling is an anodyne extension.
Both operations preserve homotopy equivalences, so the homotopy type of the simplicial set is conserved by construction.
In our case, the homotopy type remains that of a point.
\end{remark}

\begin{remark}
\label{rem:pregeometric}
Only two moves ever add an edge. A sprout adds one, and a fill in dimension two adds one. Fills in dimension three and above add no edges at all, only cells that say existing paths agree.
So every chain is built out of edges, and nothing above dimension one can be part of a chain. Whatever geometric and metric structure this model has is carried by the vertices, the edges, and the causal order between events.
Treat the edges as a multigraph.
If two fills each produce a composite, keep both as separate edges.
The number of parallel edges is a record of how many fills happened there.
The order says which events can affect which.
The edge counts say how much happened.
Both are needed, and neither replaces the other.
\end{remark}

\subsection{Events, runs, and the causal order}

Growth happens one move at a time.
A \textbf{run} is a finite sequence of move applications starting from the single vertex.
Since no move deletes anything, an event can only consume cells that already exist.
Event $b$ therefore depends on event $a$ when the match of $b$ uses a cell created by $a$, and the reflexive-transitive closure of dependency is the causal order.
A reference frame is a linearization of this order.

\begin{definition}[]
\label{def:run}
A \textbf{run} is a finite ordered sequence of move applications starting from the single vertex $\Delta^0$.
Each application is an event, which may be a sprout or a fill.
\end{definition}

At any moment, a run is a partially ordered list of events representing a simplicial set.
Formally, write a run as a pair $(E, \le)$, where $E = \{e_1, \dots, e_n\}$ is the set of events and $\le$ is the causal order on them.

\begin{example}
\label{ex:run}
Start from the single vertex $v_0$.
Event $s_1$ sprouts an edge $v_0 \to v_1$, event $s_2$ sprouts an edge $v_1 \to v_2$, and event $s_3$ sprouts a second edge $v_0 \to v_3$ from the starting vertex.
Event $f$ fills the horn $v_0 \to v_1 \to v_2$, supplying the composite $v_0 \to v_2$ and its witnessing $2$-cell.
Event $s_4$ sprouts an edge $v_2 \to v_4$, and event $g$ fills the horn $v_0 \to v_2 \to v_4$, consuming the composite from $f$.
The causal order is generated by $s_1 < s_2 < f < g$ and $s_2 < s_4 < g$, while $s_3$ shares only the initial vertex with the others and stays incomparable to all of them.
The causal past of $g$ is $\past{g} = \{s_1, s_2, f, s_4, g\}$, in which $f$ and $s_4$ are incomparable, so $\Ext(\past{g}) = 2$ and $S(g) = \log 2$.
Note that the state at $g$ does not contain $v_3$, since $s_3$ is not in the causal past of $g$.
\end{example}

\begin{definition}[]
\label{def:state}
Let $e$ be an event of a run, with causal past $\past{e}$.
The \textbf{state at $e$} is the colimit of the diagram of rule applications in $\past{e}$.
\end{definition}

Since colimits depend only on the diagram and not on any ordering of it, the state at $e$ is independent of the choice of linearization, and no foliation enters into the definition of state, i.e. the state is frame-independent.

\begin{proposition}[]
\label{prop:welldef}
The dependency relation of Run~\ref{def:run} is a partial order, and the colimit in Definition~\ref{def:state} exists and is independent of linearization.
\end{proposition}

\subsection{Axioms}

With the object, the moves, and the causal order in hand, the assumptions of the framework can be stated in the vocabulary just built.

\begin{axiom}[Ontology]
\label{ax:ontology}
The fundamental object is the run, a finite sequence of non-deleting moves starting from a single vertex.
The state of the universe at an event is the colimit of that run's causal past (Definition~\ref{def:state}), so it is determined by the run rather than being independent data.
\end{axiom}

\begin{axiom}[Dynamics]
\label{ax:dynamics}
Evolution proceeds by two local, non-deleting moves: \emph{sprout} and \emph{fill} (Definition~\ref{def:moves}).
Only inner horns may be filled.
\end{axiom}

\begin{axiom}[Budget]
\label{ax:budget}
The rate of moves is fixed.
The constant $c$ is the exchange rate between translation and internal filling (Section~\ref{sec:kinematics}).
\end{axiom}

\begin{remark}[What the budget axiom leaves open]
\label{rem:budgetgaps}
A rate requires a clock, and time in this framework is emergent, a frame being only a linearization of the causal order.
Read as a universal number of moves per tick, the axiom would reinstate a preferred linearization.
The intended reading is the energetic one of \citet{margolus1998}, in which the budget bounds distinguishable changes per unit energy rather than per unit of any global time, and it awaits a notion of energy internal to the framework.
The axiom is also silent on whether the budget is one number for the whole universe or one number per region.
Locality favours the latter, and the two readings give different cosmologies (Section~\ref{sec:tower}).
\end{remark}

\begin{axiom}[Inference]
\label{ax:inference}
The probability distribution over available moves is the maximum-entropy distribution consistent with Axioms~\ref{ax:dynamics}--\ref{ax:budget} and locality (Section~\ref{sec:maxent}).
No further dynamical input is allowed.
\end{axiom}

\subsection{The entropy functional}
\label{sec:entropy}

\begin{definition}[Causal-past entropy]
\label{def:entropy}
For an event $e$ of a run,
\[
  S(e) \;=\; \log \Ext\!\big(\past{e}\big),
\]
the logarithm of the number of linear extensions of its causal past.
\end{definition}

The coarse-graining implicit in $S$ is canonical to the framework.
The state, being a colimit, forgets the order of causally independent events, and $S$ counts exactly the forgotten orderings.
A chain has $S = 0$.
An antichain of $n$ events has $S = \log n!$.
Entropy measures causal parallelism.

\begin{lemma}[Monotonicity]
\label{lem:monotone}
If $e \le e'$ then $S(e) \le S(e')$.
\end{lemma}

\subsection{Space, distance, and speed}
\label{sec:geometry}

The axioms so far say nothing about space, and no statement about speed has content until they do.
This section fixes the minimum, in order.

\begin{definition}[Weighted one-skeleton]
\label{def:weight}
Every edge created by a sprout has weight $1$.
Every composite edge created by a fill has weight equal to the total weight of the path it composes.
The \emph{distance} between two vertices is the least total weight of an undirected path between them in the one-skeleton.
\end{definition}

\begin{remark}[Fills are metrically inert]
\label{rem:inert}
A composite edge joins two vertices that were already joined by a path of exactly that weight, so under Definition~\ref{def:weight} a fill changes no distance and creates no reachability that was not already present.
The convention is forced if distance is to be stable.
Weighting every composite by $1$ instead makes each fill a shortcut, and accumulated shortcuts collapse the diameter of the complex in the manner of a small-world graph, leaving neither a stable distance function nor a bounded signal speed.
The price of Definition~\ref{def:weight} is that fills contribute nothing geometric.
What they contribute is coherence data, which is where this framework locates its physical content.
\end{remark}

\begin{definition}[Track; translation; internal evolution]
\label{def:track}
A \emph{track} is a chain in the causal order whose consecutive events are matched at cells within bounded distance of one another.
An event on a track is a \emph{translation} if it is a sprout, extending the track's locus by one unit of distance, and \emph{internal} if it is a fill, leaving the locus where it is.
\end{definition}

\begin{proposition}[A maximal signal speed]
\label{prop:maxspeed}
Along any track, distance advances by at most one unit per event, so the speed of propagation of causal influence is bounded by one unit of distance per event.
We write $c$ for this bound.
\end{proposition}
\gap{Proof to be written.
Content: by Remark~\ref{rem:inert} a fill adds no reachability, and a sprout adds one vertex at distance $1$ from its match.}

The bound of Proposition~\ref{prop:maxspeed} is not derived from anything deep.
It is the statement that the moves are local, and $c$ is a unit rather than a prediction.
What is not settled, and is the content of problem O1, is why the resulting light-cone structure should be isotropic and the same for every observer.

\subsection{Kinematics: proper time and mass}
\label{sec:kinematics}

\begin{definition}[Proper time]
\label{def:propertime}
The proper time between two causally related events is the length of the longest chain in the causal order between them.
\end{definition}

This is the causal set definition of discrete proper time.
It is frame-independent, since the longest chain is a property of the poset alone.
A null track, all of whose events are translations, has proper time zero, which recovers the statement that a photon carries no internal clock, and conversely a system with internal evolution accumulates proper time and is massive.
Mass is the rest-frame rate of internal fills, in the spirit of the Compton clock $mc^2/\hbar$.

\begin{remark}[Why longest chains, and what dilation still costs]
\label{rem:dilation}
Counting a track's own events gives the wrong dilation law.
If a track has $N$ events of which $k$ are internal, the budget splits linearly and the internal rate is $1 - v/c$, where relativity requires $\sqrt{1 - v^2/c^2}$.
The two disagree by a factor of three at $v = 0.8c$.
The quadratic form comes from the Euclidean geometry of the light-clock argument rather than from any bookkeeping over moves, which is why Appendix~\ref{app:budget} states that composition as an assumption.
Definition~\ref{def:propertime} is chosen because it is the definition for which the quadratic form is a theorem.
For a sprinkling into flat spacetime the longest chain between two events is proportional to $\sqrt{t^2 - x^2}$, and the straight route maximises it.
What that theorem assumes is that the causal order resembles a sprinkling into a Lorentzian manifold, so dilation in this framework rests on problem O1 and is not established independently of it.
\end{remark}

One further constraint the framework must respect.
Uniform motion has to be locally undetectable, so all internal processes of a moving subsystem must slow together and rate differences may only appear on reunion.
Any locally measurable change of internal rate under uniform motion would falsify the framework at once.

\subsection{The maximum-entropy problem}
\label{sec:maxent}

\begin{definition}[Move ensemble]
At a given state, let $M = M_{\mathrm{sprout}} \sqcup M_{\mathrm{fill}}$ be the set of available moves (legal sprout sites and unfilled inner horns), and let $k : M \to \mathbb{R}_{>0}$ be a cost function depending only on a move's level $d$ in the coherence tower.
\end{definition}

\begin{definition}[The inference problem]
\label{def:maxent}
Find the probability distribution $q$ on $M$ maximizing the Shannon entropy $H(q) = -\sum_{m} q(m) \log q(m)$ subject to
\begin{enumerate}
  \item[(C1)] normalization, $\sum_m q(m) = 1$;
  \item[(C2)] budget, $\mathbb{E}_q[k] = R$;
  \item[(C3)] locality and homogeneity: $q(m)$ depends only on the isomorphism class of the local neighbourhood of $m$'s match.
\end{enumerate}
\end{definition}

\begin{conjecture}[Gibbs rule]
\label{conj:gibbs}
The problem of Definition~\ref{def:maxent} has a unique solution of the form $q(m) \propto e^{-\lambda k(m)}$ with a single multiplier $\lambda(R)$.
The sprout-to-fill ratio and the expansion law $N(t)$ are then determined by the level degeneracies (Catalan counts) and $k$, with no further choices.
\end{conjecture}

\subsection{Coherence escalation and the growth law}
\label{sec:tower}

Filling promotes questions up the associahedral tower (Section~\ref{sec:prerequisites}), where a question is an unfilled inner horn.
A fill at level $d$ mints questions at level $d+1$, with supply growing like $4^d$, so completion never depletes the supply of available moves and no region ever finishes.

The tower taxes fills alone.
Sprouts have constant cost and remain available at every vertex, and by Remark~\ref{rem:inert} fills are metrically inert, so the growth of space is carried by sprouts and coherence escalation exerts no direct brake on it.
The tower acts only through competition for budget, and under a Gibbs rule expensive moves lose share, so the mix shifts towards sprouting as the typical level rises.

The growth law is therefore decided by the second question of Remark~\ref{rem:budgetgaps}.
With one budget for the whole universe the move rate saturates at a constant once cheap sprouts dominate, vertex count grows linearly, and the scale factor decelerates.
With a budget per region the total activity is proportional to the number of vertices, growth is exponential, and the late universe is a de Sitter phase.
Locality favours the second reading.
We assert neither, and we draw no comparison with the observed history of deceleration followed by late-time acceleration, since Remark~\ref{rem:pregeometric} and problem O4 stand between vertex count and any scale factor.
